API Reference

A REST API for reading and writing tasks, boards and team data in super_vibe. All responses are JSON.

Authentication

Every request needs an API key in the Authorization header. Generate a key from Settings → API in your workspace.

# Example request
curl https://api.supervibe.app/v1/tasks \
  -H "Authorization: Bearer YOUR_API_KEY"

Rate limits

Requests are limited to 600 per minute per API key. The current limit and remaining quota are returned in response headers.

HeaderDescription
X-RateLimit-LimitRequests allowed per minute
X-RateLimit-RemainingRequests remaining in the current window

Tasks

GET/v1/tasks

Returns a paginated list of tasks across your workspace.

{
  "id": "tsk_8f2a",
  "title": "Draft homepage copy",
  "status": "in_progress",
  "assignee": "jamie@studio.com",
  "due_date": "2026-09-20"
}
POST/v1/tasks

Creates a new task on a given board.

curl -X POST https://api.supervibe.app/v1/tasks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"title":"New task","board_id":"brd_12"}'

Boards

GET/v1/boards

Returns all boards visible to the authenticated user.

Users

GET/v1/users/me

Returns the profile of the currently authenticated user.
